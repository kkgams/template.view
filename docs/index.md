# View documentation

`view.example` is a minimal GAMS View Project Unit. It renders a greeting inside
an Area and registers/unregisters through the Host's View plugin helper.

Read [development](#/development), [public API](#/api), and
[installation](#/installation). Replace these pages with your Unit's own docs.
